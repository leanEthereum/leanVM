# Function boundaries of the guest's verifier. scripts/nostd-verifier.sh gives every function with a body in the
# no_std copy `#[inline(always)]` if it is listed here and `#[inline(never)]` otherwise, replacing any `#[inline]` the
# source has, so that which functions exist in the image does not depend on LLVM's size heuristics.
#
# One function per line: the file, then the function as `name` (free), `Type::name` (inherent) or
# `Trait for Type::name` (trait impl), with the impl's header as written after `impl<..>`. Listed here: straight-line
# bodies without loops or allocation, inlined so that a caller's proof executes them in place. Field multiplication
# (`base_mul`, `Mul for E::mul`) stays a function: it is what other proofs call by contract.
