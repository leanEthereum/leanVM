- (plan) The formula counts the kernel dimension of the pattern of a given list. A list exists iff the kernel of its exact coincidence pattern contains a point with distinct rows, i.e. iff for no merge of members the kernel is the same. So the constraint "formula => list" is: dim ker P(pi) > dim ker P(pi merged a ~ b) for every pair a, b (a strict drop for every merge), or at least dim ker P(pi) >= 1 with every row nonzero. Each of these is computable from (C*) since merged patterns are again patterns.
- (derived, to be written properly) Exactness remark: a list with class pattern P exists iff no e_a + e_b lies in Theta(P) (the functionals killing every solution), i.e. iff r(P/ab) > r(P) - ... for every pair; so an exact rank formula decides list existence exactly: the question is whether the resulting combinatorial problem can be solved, not whether the formula is "strong enough" logically.
- (derived) Counting: a list of L+1 at agreement 5n/8 = 5k/4 has w >= (L+1) 5k/4 - 2k and r <= Lk - 1, so deficiency delta = w - r >= (L-3)k/4 + 1; the same for every sub-list of s+1 members: delta_S >= (s-3)k/4 + 1. So (S8) <=> deficiency of list patterns is O(k) ... (in fact L + 1 <= 4 + 4 (delta - 1)/k).
- (derived, under (C*) on the chain) identity: with c_u = codim Delta_u, s_u = dim(Delta_p cap Q_u^perp) - dim Delta_u >= 0 (slack), c_u = c_p + rho_u + s_u, and delta = sum_j 2^j sum_{u ht j} s_u - sum_x (c_x - kappa_x). Deficiency = weighted slack.
