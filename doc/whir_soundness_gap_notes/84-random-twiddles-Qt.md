## 0. Summary

**The theorem as proved, its constants, the list thresholds over $K$, and what is only sketched.** *Theorem 5.1 (proved, not refereed):* let the top $J$ levels be fixed so that every genuine one-functional system on $T_J$ with directions in a fixed finite set $\Delta \subset K^L \setminus 0$ has independent rows (for $J = 0$ this is empty: nothing is checked and every twiddle is random), and let the twiddles below be uniform (T2), $n \le 2^{26}$. Then for every $\lambda \in (0, 64)$, except with probability $p$, **every genuine one-functional system $X$ of leaves with directions in $\Delta$ has rank above $|X| - \varepsilon_\Delta n$**, with $\varepsilon_\Delta = \big(\lambda L\rho + \tfrac12 C_J + \tfrac12\log_2(1 + |\Delta|2^{-2\lambda - C_J}) + (\log_2(\mathcal L/p) + c_\kappa)/n_{J+1}\big)/(64 - \lambda)$, $C_J = \sum_i \log_2(1 + 2|\Delta|2^{-\lambda_i} + |\Delta|(|\Delta| - 1)2^{-2\lambda_i})$, $\lambda_i = \lambda + C_{i+1}/2$ (exact recursion in Section 4; $c_\kappa$ is between 4.7 and 14.8 bits in the cases computed; a top with excess $a$ adds $\frac{64}{64-\lambda}a/n_J$). In particular ($\Delta$ = the $\binom t2$ differences, $L = t - 1$): **any $t$ distinct codewords, with symbols in any extension field, coincide pairwise on fewer than $(t-1)k + \varepsilon_t n$ leaves**, for every $t$ with $(t-1)\rho < 1$. ## 1. Setting and notation

Notation of note 73 throughout: $K = \mathrm{GF}(2^{64})$, $q = |K|$, rate $\rho = 2^{-r}$, $k = 2^v$, $n = 2^{v+r}$, $P_j$ the level-$j$ nodes, $n_j = 2^{j+r}$, $k_j = 2^j$, $u_j = n/n_j$, $T_j$ the code of the top $j$ levels with rows $g_p \in K^{k_j}$, children $(p,0), (p,1)$ of $p \in P_j$ with twiddles $t_{p,0} \ne t_{p,1}$ and $g_{(p,b)} = (g_p, t_{p,b} g_p)$. Ensemble T2: $T_J$ fixed, and for $j \ge J$ the pairs $(t_{p,0}, t_{p,1})$, $p \in P_j$, independent of each other and of the coarser levels, each uniform on ordered pairs of distinct elements of $K$. $\mathcal L = v - J$ is the number of random levels (note 73 writes $L$; here $L$ is the number of differences).

**Systems.** Fix $L \ge 1$ and a finite set $\Delta$ of nonzero vectors of $K^L$, pairwise non-proportional (the *directions*; they are fixed before the twiddles are drawn; no subfield condition is needed). The case of the brief is $\Delta_t = \{e_a - e_b : 0 \le a < b \le L\}$ with $e_0 = 0$, $t = L + 1$, $|\Delta_t| = \binom t2$. A (one-functional) *system* at level $j$ is a set $Y \subseteq P_j$ with a direction $\lambda_p \in \Delta$ for each $p \in Y$. Unknown: $M \in K^{L \times k_j}$ (rows: the differences $m_l - m_0$ of $t$ messages). Equations: $\lambda_p^T M g_p = 0$, $p \in Y$; rows $\lambda_p \otimes g_p \in K^L \otimes K^{k_j}$, row space $R_j(Y)$, solution space $N_j(Y) = R_j(Y)^\perp$, $\mathrm{null}_j(Y) = \dim N_j(Y)$, $\mathrm{rk}_j(Y) = Lk_j - \mathrm{null}_j(Y)$, excess $e_j(Y) = |Y| - \mathrm{rk}_j(Y) = |Y| - Lk_j + \mathrm{null}_j(Y) \ge 0$ (the number of independent relations between the rows). Leaf units: $\mathcal N_j = u_j\,\mathrm{null}_j$, $\mathcal E_j = u_j e_j$. A system is *genuine* if for every $p \in Y$ some $M \in N_j(Y)$ has $\lambda_p^T M \ne 0$ (note 74's definition). For $L = 1$, $\Delta = \{1\}$: a system is a set of zeros, genuine iff nonempty with $\mathrm{null} \ge 1$, and everything below is note 73.

**Why genuine systems are the object (proved, one line).** If $m_0, \dots, m_L$ are distinct messages and $X$ is the set of leaves where at least two of the codewords coincide, choose at each $x \in X$ one coinciding pair $(a,b)$ and put $\lambda_x = e_a - e_b$: the matrix $M$ of differences solves the system and $\lambda_x^T M = m_a - m_b \ne 0$, so the system is genuine, $\mathrm{null}_v(X) \ge 1$ and $|X| = Lk - \mathrm{null}_v(X) + e_v(X) \le (t-1)k - 1 + e_v(X)$. So "$Q_t$ with slack $s$" follows from "every genuine system with directions in $\Delta_t$ has $e_v \le s$".

For a message of $T_{j+1}$ write $M = (M_0, M_1) \in (K^{L \times k_j})^2$ and $\alpha_p(M) = M_0 g_p$, $\beta_p(M) = M_1 g_p \in K^L$; the vector of symbols at $(p,b)$ is $\alpha_p(M) + t_{p,b}\beta_p(M)$.

## 2. One level: the splitting lemma with directions

Fix $j \ge J$ and condition on $T_j$. An *event label* at level $j$ is a pair $(Y, D)$: a system $Y$ at level $j$ and a set $D \subseteq P_{j+1}$ with a direction $\lambda_x \in \Delta$ for each $x \in D$ (no restriction on where $D$ sits: its elements may be children of nodes of $Y$, and both children of a node may be in $D$). Put
$$S(Y, D) = \{M \in N_j(Y)^2 : \lambda_x^T(\alpha_{p}(M) + t_x \beta_{p}(M)) = 0\ \ \forall x = (p, b) \in D\}, \qquad G(Y, D) = \dim S(Y,D) - (2\,\mathrm{null}_j(Y) - |D|).$$
The label is *tight* if for every $x = (p,b) \in D$ the functional $\lambda_x^T\beta_p$ is not identically zero on $S(Y,D)$.

**Lemma 2.1 (splitting lemma with directions; proved).** (a) $0 \le G(Y,D) \le |D|$. (b) If the label is tight then no node has both children in $D$ with the same direction. (c) For every label with $|D| < q/2$ and every integer $g \ge 1$: $\Pr[\text{tight and } G(Y,D) \ge g \mid T_j] \le q^{-g}/(1 - 2|D|/q)$.

*Proof.* (a) $S$ is cut out of $N_j(Y)^2$ by $|D|$ linear conditions. (b) If $(p,0), (p,1) \in D$ carry the same $\lambda$, subtracting the two conditions gives $(t_{p,0} - t_{p,1})\lambda^T\beta_p = 0$ on $S$, and $t_{p,0} \ne t_{p,1}$. (c) Let $m = 2\,\mathrm{null}_j(Y)$, $d = |D|$. On the event "tight and $\dim S = \delta$" the sets $S_x = \{M \in S : \lambda_x^T\beta_p(M) = 0\}$ are proper subspaces of $S$, so $S^\circ = S \setminus \bigcup_x S_x$ has at least $q^\delta(1 - d/q)$ elements, and for $M \in S^\circ$, $x \in D$: $t_x = \lambda_x^T\alpha_p(M)/\lambda_x^T\beta_p(M)$. For $\sigma \in K^D$ let $W_\sigma = \{M \in N_j(Y)^2 : \lambda_x^T\beta_p(M) \ne 0,\ \lambda_x^T\alpha_p(M) = \sigma_x \lambda_x^T\beta_p(M)\ \forall x \in D\}$, a set determined by $T_j$; the $W_\sigma$ are pairwise disjoint and $S^\circ \subseteq W_{(t_x)_{x \in D}}$. So the event implies $(t_x)_{x \in D} \in \Sigma_\delta = \{\sigma : |W_\sigma| \ge q^\delta(1 - d/q)\}$, $|\Sigma_\delta| \le q^{m - \delta}/(1 - d/q)$, and the $\Sigma_\delta$ decrease in $\delta$. Given $T_j$, the vector $(t_x)_{x \in D}$ takes each value with probability at most $q^{-d_1}(q(q-1))^{-d_2}$, where $d_1$ nodes have one child in $D$ and $d_2$ have two ($d = d_1 + 2 d_2$; T2: a pair is uniform on ordered distinct pairs, pairs of distinct nodes are independent), which is at most $q^{-d}(1 - 1/q)^{-d/2}$. Hence $\Pr[\text{tight}, \dim S \ge \delta \mid T_j] \le q^{m - \delta - d}(1 - d/q)^{-1}(1 - 1/q)^{-d/2} \le q^{m - \delta - d}/(1 - 2d/q)$; put $\delta = m - d + g$. $\square$

**What changed from note 73's Lemma 2.1.** Nothing in the proof: because each element of $D$ carries ONE functional, a non-rounded element still determines its twiddle as one slope, and one condition is paid by one coincidence. (With a label of dimension $c - 1 \ge 2$ at a leaf, only one of its $c - 1$ conditions is paid; this is the "determinantal" loss of note 68 Section 5 item (4), and it is the reason the whole argument is run on one-functional systems.) The new points are all in the bookkeeping one level up, Section 3: two children of a node may now be *rounded* with different directions, and then the node carries a plane, not a line.

**Road map of Sections 3 to 9.**
1. Rounded and tight elements of a system $Y_{i+1}$ at level $i+1$ (with respect to its own solution space): $x = (p,b)$ is *rounded* if $\lambda_x^T\alpha_p \equiv \lambda_x^T\beta_p \equiv 0$ on $N_{i+1}(Y_{i+1})$, *tight* if $\lambda_x^T\beta_p \not\equiv 0$; every element is one or the other. Parent system $Y_i$: the nodes with a rounded child, with that child's direction.
2. Reduction lemma: if two rounded siblings carry different directions $\lambda, \mu$, rewriting $\mu \to \lambda$ on all leaves that are "rounded all the way up" below the second sibling gives a genuine system on the same leaves with row space contained in the old one, hence excess at least as large. A potential (sum of the indices of the directions) decreases, so every genuine system is dominated by a *reduced* one: rounded siblings always carry the same direction.
3. For a reduced system the chain is exact: $e_{i+1}(Y_{i+1}) = 2 e_i(Y_i) + G(Y_i, D_{i+1}) - h_i$, $h_i$ = number of nodes of $Y_i$ with exactly one rounded child, and $\mathrm{null}_{i+1} = 2\,\mathrm{null}_i - |D_{i+1}| + G$. So $2\,\mathrm{null}_j(Y)$ of note 73 is replaced by $2\,\mathrm{null}_i(Y_i)$ of the one-functional parent system, and a half-rounded node costs one unit of excess (it pays for its own entropy).
4. Prefix code: per level, a node outside $Y_i$ has $1 + 2|\Delta| x + |\Delta|(|\Delta| - 1)x^2$ weighted options ($x = 2^{-\lambda_i}$), a node of $Y_i$ has the doubling (weight 1) and $2 + 2(|\Delta| - 1)x$ half-rounded options of weight $2^{-\eta_i}$. Kraft with equality, top-down conditioning as in note 73 Lemma 4.1.
5. Theorem: $e_v(X) < \varepsilon_\Delta n$ with $\varepsilon_\Delta = \big(\lambda L \rho + \tfrac12 C_J + \dots + (\log_2(\mathcal L/p) + c_\kappa)/n_{J+1}\big)/(64 - \lambda)$, $C_J$ as in note 73 with $2^{1-\lambda_i}$ replaced by the polynomial above. Top condition: every genuine system on $T_J$ has independent rows; trivially true at $J = 0$.
6. Linear program of note 75 with $j\rho + \varepsilon_{j+1}$ on the right, dual certificates, thresholds at the four rates.
7. Toy check over GF($2^8$), $n = 16$, three codewords.

## 3. Rounded and tight elements, the reduction lemma, and the exact chain

Everything in this section is deterministic (any twiddles with $t_{p,0} \ne t_{p,1}$).

**Definition (rounded, tight, parent).** Let $Y$ be a system at level $i + 1$ and $S = N_{i+1}(Y)$. An element $x = (p, b) \in Y$ is *rounded* if $\lambda_x^T\alpha_p \equiv 0$ and $\lambda_x^T\beta_p \equiv 0$ on $S$, and *tight* if $\lambda_x^T\beta_p \not\equiv 0$ on $S$. $R(Y)$, $D(Y)$ are the sets of rounded and tight elements. $Y$ is *reduced at its level* if two rounded siblings always carry the same direction. If so, the *parent system* $Y^\uparrow$ at level $i$ is the set of nodes with at least one rounded child, with that child's direction; $h(Y)$ is the number of nodes of $Y^\uparrow$ with exactly one rounded child.

**Lemma 3.1 (dichotomy and row-space form; proved).** (a) Every element of $Y$ is rounded or tight, not both. (b) $x = (p,b)$ is rounded iff $(\lambda_x \otimes g_p) \otimes K^2 \subseteq R_{i+1}(Y)$. (c) Two siblings of $Y$ with the same direction are both rounded. (d) If $Y$ is genuine and reduced at its level, then $Y^\uparrow$ is genuine, $R_i(Y^\uparrow) \otimes K^2 \subseteq R_{i+1}(Y)$, a tight child of a node $p \in Y^\uparrow$ has a direction different from $\lambda_p$, and
$$N_{i+1}(Y) = S(Y^\uparrow, D(Y)), \qquad \mathrm{null}_{i+1}(Y) = 2\,\mathrm{null}_i(Y^\uparrow) - |D(Y)| + G, \qquad e_{i+1}(Y) = 2\,e_i(Y^\uparrow) + G - h(Y),$$
with $G = G(Y^\uparrow, D(Y))$, and the label $(Y^\uparrow, D(Y))$ is tight.

*Proof.* (a) On $S$, $\lambda_x^T\alpha_p + t_x\lambda_x^T\beta_p \equiv 0$; so $\lambda_x^T\beta_p \equiv 0$ implies $\lambda_x^T\alpha_p \equiv 0$. (b) $R_{i+1}(Y) = S^\perp$, and $M = (M_0, M_1)$ is orthogonal to $(\lambda \otimes g_p) \otimes (a, b)$ for all $(a,b)$ iff $\lambda^T M_0 g_p = \lambda^T M_1 g_p = 0$. (c) Lemma 2.1(b)'s computation. (d) Slices: if $M \in S$ then $M_0, M_1$ satisfy $\lambda_p^T M_c g_p = 0$ for $p \in Y^\uparrow$ (a rounded child), so $M_0, M_1 \in N_i(Y^\uparrow)$; and $\lambda_p$ is the direction of an element of $Y$, so some $M \in S$ has $\lambda_p^T M \ne 0$, hence $\lambda_p^T M_0 \ne 0$ or $\lambda_p^T M_1 \ne 0$: $Y^\uparrow$ is genuine. The inclusion of row spaces is (b). A child of $p \in Y^\uparrow$ with direction $\lambda_p$ is rounded, by the definition of $N_i(Y^\uparrow)$ and the slices. $S \subseteq S(Y^\uparrow, D)$: slices, and the conditions of $D$ hold on $S$. Conversely an $M \in N_i(Y^\uparrow)^2$ satisfies the equation of every rounded $x = (p,b)$, because $\lambda_x = \lambda_p$ ($Y$ is reduced) and $\lambda_p^T(M_0 + t_x M_1) g_p = 0$; with the conditions of $D$ it satisfies all of $Y$. So $S = S(Y^\uparrow, D)$, tight by the definition of $D$. Then $\dim S = 2\,\mathrm{null}_i(Y^\uparrow) - |D| + G$ is the definition of $G$, and with $|Y| = |R| + |D|$, $|R| = 2|Y^\uparrow| - h$, $k_{i+1} = 2k_i$: $e_{i+1}(Y) = |R| + |D| - 2Lk_i + \dim S = 2(|Y^\uparrow| - Lk_i + \mathrm{null}_i(Y^\uparrow)) + G - h$. $\square$

**Remark (what replaces $2\,\mathrm{null}_j(Y)$, and the answer to "the right notion of rounded set").** If two rounded siblings carry different directions $\lambda \ne \mu$, the node really carries the plane $\langle \lambda, \mu\rangle$ (both slices are orthogonal to both), and the exact statement is $e_{i+1}(Y) = 2 e_i(\Lambda^\uparrow) + G - h - 2\varrho_2$ with $\Lambda^\uparrow$ the subspace-labelled set one level up and $\varrho_2$ the number of such nodes. A subspace-labelled set of dimension 2 or more at a node is where the slope count loses (one coincidence for $c - 1$ conditions) and where the directions stop being in a finite set (the rounded part of a plane is any of its $q + 1$ lines). Lemma 3.2 avoids both: it shows that planes never need to be carried.

**The chain.** For a genuine system $X$ of leaves put $Y_v = X$ and, as long as $Y_{i+1}$ is reduced at its level, $Y_i = Y_{i+1}^\uparrow$ (genuine by Lemma 3.1(d)). $X$ is *reduced* (down to level $J$) if $Y_v, \dots, Y_{J+1}$ are all reduced at their levels; then $Y_J$ is defined. For a node $y \in Y_{i+1}$ let $B(y)$ be the set of leaves below $y$ that are rounded all the way up to $y$: $x \in R(Y_v)$, its ancestor at level $v - 1$ in $R(Y_{v-1})$, and so on up to the ancestor at level $i + 2$ in $R(Y_{i+2})$ (for $i + 1 = v$, $B(y) = \{y\}$). $B(y)$ is not empty (every node of a parent system has a rounded child) and all its leaves carry the direction of $y$.

**Lemma 3.2 (reduction; proved).** For every genuine system $X$ of leaves there is a reduced genuine system $X^*$ on the same set of leaves, with directions among those of $X$, such that $R_v(X^*) \subseteq R_v(X)$, hence $e_v(X^*) \ge e_v(X)$ and $\mathrm{null}_v(X^*) \ge \mathrm{null}_v(X)$.

*Proof.* Fix a total order on $\Delta$. Suppose $X$ is not reduced, and let $i + 1$ be the deepest level (largest index) at which the chain stops: $Y_v, \dots, Y_{i+2}$ are reduced at their levels and $Y_{i+1}$ has two rounded siblings $(p,0), (p,1)$ with directions $\lambda < \mu$, the larger one $\mu$ at $y = (p, b)$. Let $X'$ be $X$ with the direction of every leaf of $B(y)$ changed from $\mu$ to $\lambda$. (1) $\lambda \otimes g_p \otimes K^2 \subseteq R_{i+1}(Y_{i+1})$ by Lemma 3.1(b) for the sibling of $y$, so $\lambda \otimes g_y \in R_{i+1}(Y_{i+1})$. (2) $R_m(Y_m) \otimes K^2 \subseteq R_{m+1}(Y_{m+1})$ for $m = i+1, \dots, v-1$ (Lemma 3.1(d)), so $\lambda \otimes g_y \otimes (K^2)^{\otimes(v - i - 1)} \subseteq R_v(X)$; the row $g_x$ of a leaf $x$ below $y$ is $g_y$ tensored with $v - i - 1$ vectors $(1, t)$, so $\lambda \otimes g_x \in R_v(X)$ for every $x \in B(y)$. (3) Hence $R_v(X') \subseteq R_v(X)$: the changed rows are in $R_v(X)$, the others are rows of $X$. So $\mathrm{rk}_v(X') \le \mathrm{rk}_v(X)$ with $|X'| = |X|$, and $N_v(X') \supseteq N_v(X)$. (4) $X'$ is genuine: its directions are directions of $X$ ($\lambda$ is carried by the leaves of $B$ of the sibling of $y$, which are not changed), and a witness $M \in N_v(X)$ with $\nu^T M \ne 0$ is in $N_v(X')$. (5) The sum over the leaves of the rank of their direction in the order of $\Delta$ strictly decreases. So after finitely many steps the system is reduced; inclusions of row spaces compose. $\square$

**Check of the two steps that could fail.** In (2) the inclusion needs $Y_{m+1}$ reduced at its level only to define $Y_m$; the inclusion itself is Lemma 3.1(b) applied to one rounded child of each node. In (4) nothing is claimed about which elements of $X'$ are rounded or tight: the chain of $X'$ is recomputed from scratch at the next step, which is why a potential is needed and why it is a function of the leaf directions only.

**Corollary 3.3 (the chain of a reduced system; proved).** Let $X$ be genuine and reduced down to level $J$, with chain $Y_v = X, \dots, Y_J$, $D_{i+1} = D(Y_{i+1})$, $d_i = |D_{i+1}|$, $h_i = h(Y_{i+1})$, $G_i = G(Y_i, D_{i+1})$ for $J \le i \le v - 1$, $y_i = u_i|Y_i|$, and $\hat{\mathcal E} = \sum_{i=J}^{v-1} u_{i+1} G_i$, $\mathcal H = \sum_i u_{i+1} h_i$, $\Gamma_j = \sum_{i=J}^{j} G_i$. Then every $Y_i$ is genuine, every label $(Y_i, D_{i+1})$ is tight, and
1. $\mathcal E_v(X) = \mathcal E_J(Y_J) + \hat{\mathcal E} - \mathcal H$;
2. $1 \le \mathcal N_v(X) = Lk - y_J + \mathcal E_J(Y_J) + \hat{\mathcal E} - \sum_i u_{i+1} d_i$, so $\sum_i u_{i+1} d_i \le Lk - y_J + \mathcal E_J(Y_J) + \hat{\mathcal E} - 1$;
3. $y_{i+1} = y_i + u_{i+1}(d_i - h_i)$;
4. $\hat{\mathcal E} = \sum_{j=J}^{v-1}\omega_j\Gamma_j$ with $\omega_j = u_{j+1} - u_{j+2}$ ($u_{v+1} := 0$), and $\Gamma_j \le \hat{\mathcal E}/u_{j+1}$;
5. (description from the top) $Y_{i+1}$ is determined by $Y_i$ and, for each $p \in P_i$, one of the following *options*: for $p \in Y_i$ with direction $\lambda_p$: both children rounded with $\lambda_p$ (the doubling); or exactly one child rounded with $\lambda_p$ and the other absent (2 options) or tight with a direction $\mu \ne \lambda_p$ ($2(|\Delta| - 1)$ options); for $p \notin Y_i$: no child, or one tight child with any direction ($2|\Delta|$ options), or two tight children with different directions ($|\Delta|(|\Delta| - 1)$ options).

*Proof.* 1, 2: Lemma 3.1(d) at each level in leaf units ($u_{i+1} = u_i/2$), $\mathcal N_J = u_J(Lk_J - |Y_J| + e_J)$, and $\mathrm{null}_v(X) \ge 1$ because $X$ is genuine. 3: $|Y_{i+1}| = 2|Y_i| - h_i + d_i$. 4: Abel summation; $\sum_{i \le j} u_{i+1} G_i \ge u_{j+1}\Gamma_j$. 5: Lemma 3.1(c),(d) and Lemma 2.1(b). $\square$

## 4. Defect events, prefix code, good event

Fix reals $\lambda \in (0, 64)$, $\eta = (64 - \lambda)/2$, a probability $p$, and $\chi = (1 - 2n/q)^{-\mathcal L}$ ($\log_2\chi < 2^{-31}$ for $n \le 2^{26}$).

**Prefix labels.** A prefix label $\pi_j$ ($J \le j \le v - 1$) is a system $Y_J$ at level $J$ and, for each level $i = J, \dots, j$, a choice of one option of Corollary 3.3(5) for every $p \in P_i$, where $Y_{i+1}$ is the system that $Y_i$ and the options of level $i$ determine (rounded children of $p \in Y_i$ inherit $\lambda_p$) and $D_{i+1}$ its set of children declared tight. It is a combinatorial object; it determines the labels $(Y_i, D_{i+1})$, $i \le j$, and the numbers $d_i = |D_{i+1}|$, $h_i$ (half-rounded nodes), $m_i = n_i - |Y_i|$.

**Multipliers (backward recursion).** $C_v = C'_v = 0$ and for $i = v - 1$ down to $J$, with $B_{i+1} = \tfrac12(C_{i+1} - C'_{i+1})$:
$$\lambda_i = \lambda + B_{i+1},\quad \eta_i = \eta - B_{i+1},\quad c_i = \log_2\!\big(1 + 2|\Delta| 2^{-\lambda_i} + |\Delta|(|\Delta| - 1) 2^{-2\lambda_i}\big),\quad c'_i = \log_2\!\big(1 + 2^{1 - \eta_i}(1 + (|\Delta| - 1)2^{-\lambda_i})\big),$$
$C_i = C_{i+1} + c_i$, $C'_i = C'_{i+1} + c'_i$; and $\lambda'_J = 2\lambda + C_J - C'_J$. ($c_i$ is the price of a node outside $Y_i$, $c'_i$ of a node of $Y_i$; $C'_J$ is below $10^{-5}$ in every case used in Sections 7 and 8.)

**Code length.** $w(\pi_j) = \lambda'_J|Y_J| + n_J\log_2(1 + |\Delta| 2^{-\lambda'_J}) + \sum_{i=J}^{j}\big(\lambda_i d_i + \eta_i h_i + m_i c_i + |Y_i| c'_i\big)$. For $J = 0$ the only genuine system on $T_0$ is empty (Section 6), so prefix labels have $Y_0 = \emptyset$ and the first two terms are dropped.

**Lemma 4.1 (Kraft equality; proved).** $\sum_{\pi_j} 2^{-w(\pi_j)} = 1$ for each $j$. *Proof.* Given $Y_i$, the options of a node outside $Y_i$ have total weight $1 + 2|\Delta|x + |\Delta|(|\Delta|-1)x^2 = 2^{c_i}$ ($x = 2^{-\lambda_i}$: one factor $x$ per tight child), those of a node of $Y_i$ have $1 + 2z + 2(|\Delta| - 1)xz = 2^{c'_i}$ ($z = 2^{-\eta_i}$: one factor $z$ per half-rounded node). So the sum over the options of level $i$ of $2^{-(\lambda_i d_i + \eta_i h_i + m_i c_i + |Y_i| c'_i)}$ is 1 whatever $Y_i$ is; induct from the last level up, and $\sum_{Y_J} 2^{-\lambda'_J|Y_J|} = (1 + |\Delta|2^{-\lambda'_J})^{n_J}$. $\square$

**Defect events.** $A(\pi_j, \Gamma)$ = "every label $(Y_i, D_{i+1})$, $J \le i \le j$, of $\pi_j$ is tight and $\sum_{i=J}^{j} G(Y_i, D_{i+1}) \ge \Gamma$" (an event of the twiddles of levels $J+1..j+1$).

**Lemma 4.2 (top-down conditioning; proved).** $\Pr[A(\pi_j, \Gamma)] \le \binom{\Gamma + j - J}{j - J}\chi\, q^{-\Gamma}$. *Proof.* Word for word note 73's Lemma 4.1 with Lemma 2.1(c) above: choose $0 \le g_i \le G_i$ with sum $\Gamma$; $B_i$ = "label $i$ tight and $G_i \ge g_i$" has $\Pr[B_i \mid T_i] \le q^{-g_i}/(1 - 2n/q)$ for every value of $T_i$ (the label is deterministic), and $B_J, \dots, B_{i-1}$ are functions of $T_i$. $\square$

**Good event.** $\kappa_j(\Gamma) = \log_2\binom{\Gamma + j - J}{j - J}$; $\Gamma^*(\pi_j)$ is the least integer $\Gamma \ge 1$ with $64\Gamma - \kappa_j(\Gamma) \ge w(\pi_j) + \log_2(\mathcal L\chi/p)$; $\mathcal G_\Delta(\lambda, p)$ is the event that $A(\pi_j, \Gamma^*(\pi_j))$ fails for every $j$ and every $\pi_j$.

**Lemma 4.3 (proved).** $\Pr[\lnot\mathcal G_\Delta(\lambda, p)] \le p$ for any fixed $T_J$. On $\mathcal G_\Delta(\lambda,p)$ every prefix label all of whose labels are tight has $64\,\Gamma_j - \kappa_j(\Gamma_j) < w(\pi_j) + \log_2(\mathcal L\chi/p)$ $(\star)$. *Proof.* Note 73's Lemma 4.2: $\Pr[A(\pi_j, \Gamma^*)] \le 2^{-w(\pi_j)} p/\mathcal L$, Kraft, $\mathcal L$ levels; $\Gamma \mapsto 64\Gamma - \kappa_j(\Gamma)$ is increasing. $\square$

## 5. The theorem

**Top condition $\mathrm{Top}_\Delta(a)$.** Every genuine system on $T_J$ with directions in $\Delta$ has excess $e_J \le a$. ($a = 0$: the rows of every genuine system on $T_J$ are independent, the exact property of note 74's Theorem 4.2 for the top code. For $L = 1$ it is "MDS". Section 6 says when it holds and when it can be checked.)

**Constants.** With $C_J, C'_J$ of Section 4 ($\eta = (64-\lambda)/2$):
$$M_\Delta(\lambda) = \lambda L\rho + \tfrac12 C_J + \tfrac12\log_2\!\big(1 + |\Delta|\,2^{-2\lambda - C_J + C'_J}\big)\ \ (\text{last term absent if } J = 0), \qquad c_\kappa(\hat\varepsilon) = \sum_{j=J}^{v-1}\frac{\omega_j}{u_{J+1}}\log_2\binom{\lfloor\hat\varepsilon n_{j+1}\rfloor + j - J}{j - J},$$
$$\Psi(\hat\varepsilon) = M_\Delta(\lambda) + \frac{\log_2(\mathcal L/p) + 2^{-31} + c_\kappa(\hat\varepsilon)}{n_{J+1}}, \qquad \hat\varepsilon_0 = \text{the eventual value of } \hat\varepsilon^{(0)} = \mathcal L,\ \ \hat\varepsilon^{(s+1)} = \frac{2}{64-\lambda}\Big(\Psi(\hat\varepsilon^{(s)}) + \frac{(64 + \lambda)\,a}{2\,n_J}\Big),$$
$$\varepsilon_\Delta = \varepsilon_\Delta(\lambda; r, v, J, p, a) = \frac{\Psi(\hat\varepsilon_0)}{64 - \lambda} + \frac{64}{64-\lambda}\cdot\frac{a}{n_J}.$$

**Theorem 5.1 (proved).** Let $r \ge 1$, $0 \le J < v$, $n = 2^{v+r} \le 2^{26}$, $L \ge 1$, $\Delta \subset K^L \setminus 0$ a fixed finite set of pairwise non-proportional directions, $T_J$ any fixed code of the top $J$ levels with $\mathrm{Top}_\Delta(a)$, and the twiddles of levels $J+1, \dots, v$ random as in T2. Then for every $\lambda \in (0, 64)$ and $p > 0$, with probability at least $1 - p$ (on $\mathcal G_\Delta(\lambda, p)$): **every genuine one-functional system $X$ of leaves with directions in $\Delta$ has $e_v(X) < \varepsilon_\Delta n$, that is, $\mathrm{rk}_v(X) > |X| - \varepsilon_\Delta n$.** Consequently, on that event, with $\Delta = \Delta_t$ ($L = t - 1$, $|\Delta| = \binom t2$), writing $\varepsilon_t = \varepsilon_{\Delta_t}$:
1. **($Q_t$ with slack)** for any $t$ distinct codewords, the number of leaves at which at least two of them coincide is less than $(t-1)k + \varepsilon_t n$;
2. the same for $t' \le t$ distinct codewords with $(t' - 1)k + \varepsilon_t n$ (a system with directions in $\Delta_{t'} \subseteq \Delta_t$; but $\varepsilon_{t'}$ on its own event is smaller);
3. symbols in an extension field cost nothing: the rank of a system over $K$ is its rank over any extension, so the statement holds for codewords of $T_v \otimes E$.

*Proof.* Let $X$ be genuine. By Lemma 3.2 there is a reduced genuine $X^*$ with $e_v(X^*) \ge e_v(X)$; take its chain (Corollary 3.3). The combinatorial data of the chain ($Y_J$ and the options at each level) form a prefix label $\pi$ whose labels $(Y_i, D_{i+1})$ are all tight, so on $\mathcal G_\Delta$ the inequality $(\star)$ holds for every $j$. Multiply by $\omega_j$ and sum (Corollary 3.3(4)): $64\hat{\mathcal E} < u_{J+1}\big(\lambda'_J|Y_J| + n_J\log_2(1 + |\Delta|2^{-\lambda'_J}) + \log_2(\mathcal L\chi/p)\big) + \sum_i u_{i+1}(\lambda_i d_i + \eta_i h_i + m_i c_i + |Y_i| c'_i) + \sum_j\omega_j\kappa_j(\Gamma_j)$.
- Step 1. $u_{i+1} m_i = \tfrac12(n - y_i)$, $u_{i+1}|Y_i| = \tfrac12 y_i$, and $y_i = y_J + \sum_{i' < i} u_{i'+1}(d_{i'} - h_{i'})$ (Corollary 3.3(3)). So $\sum_i u_{i+1}(m_i c_i + |Y_i| c'_i) = \tfrac12 n C_J - \tfrac12\sum_i y_i(c_i - c'_i) = \tfrac12 nC_J - y_J B_J - \sum_{i'} u_{i'+1}(d_{i'} - h_{i'}) B_{i'+1}$.
- Step 2. With $\lambda_i = \lambda + B_{i+1}$, $\eta_i = \eta - B_{i+1}$: $\sum_i u_{i+1}(\lambda_i d_i + \eta_i h_i + m_i c_i + |Y_i|c'_i) = \lambda\sum_i u_{i+1} d_i + \eta\,\mathcal H + \tfrac12 nC_J - y_J B_J$.
- Step 3 (nullity budget, Corollary 3.3(2)). $\lambda\sum_i u_{i+1}d_i \le \lambda(Lk - y_J + \mathcal E_J + \hat{\mathcal E} - 1)$.
- Step 4. The terms in $y_J$: $u_{J+1}\lambda'_J|Y_J| - y_J B_J - \lambda y_J = y_J(\tfrac12\lambda'_J - B_J - \lambda) = 0$.
- Step 5. $\kappa_j(\Gamma_j) \le \log_2\binom{\lfloor\hat{\mathcal E}/u_{j+1}\rfloor + j - J}{j - J}$, so $\sum_j\omega_j\kappa_j(\Gamma_j) \le u_{J+1}c_\kappa(\hat\varepsilon)$ with $\hat\varepsilon = \hat{\mathcal E}/n$.

Dividing by $n$ ($u_{J+1}n_J = n/2$, $\mathcal E_J \le u_J a$): $(64 - \lambda)\hat\varepsilon - \eta\mathcal H/n < \Psi(\hat\varepsilon) + \lambda a/n_J$. Two uses. (i) $\hat{\mathcal E} - \mathcal H = \mathcal E_v - \mathcal E_J \ge -u_J a$ gives $(64-\lambda)\hat\varepsilon - \eta\mathcal H/n \ge (64 - \lambda - \eta)\hat\varepsilon - \eta a/n_J$, so $\hat\varepsilon < \frac{2}{64-\lambda}(\Psi(\hat\varepsilon) + (\lambda + \eta)a/n_J)$; since a priori $\hat{\mathcal E} \le \sum_i u_{i+1}d_i \le \mathcal L n$ and $\Psi$ is nondecreasing, $\hat\varepsilon < \hat\varepsilon_0$ as in note 73. (ii) $\eta \le 64 - \lambda$ gives $(64-\lambda)\hat\varepsilon - \eta\mathcal H/n \ge (64-\lambda)(\hat{\mathcal E} - \mathcal H)/n = (64-\lambda)(\mathcal E_v(X^*) - \mathcal E_J)/n$, so $(64 - \lambda)\mathcal E_v(X^*)/n < \Psi(\hat\varepsilon_0) + 64a/n_J$. Item 1 is Section 1; item 3 is linear algebra. $\square$

**Referee checks on my own proof.** (i) The realized chain is that of $X^*$, not of $X$: only $e_v(X) \le e_v(X^*)$ is used, and $(\star)$ holds for all prefix labels at once. (ii) The Kraft sum is over all combinatorial prefix labels, including those that are the chain of no system. (iii) A half-rounded node lowers the excess by one unit at its level (Corollary 3.3(1)) and is charged $\eta$ bits; $\eta \le 64 - \lambda$ is exactly what makes it pay for itself, and $\eta > 0$ what keeps $C'_J$ negligible. (iv) The directions enter three times: $|\Delta|$ in $c_i$ (the union over directions), $L$ in the budget $Lk$, and the top condition. (v) For $L = 1$, $\Delta = \{1\}$ the options with a tight child under a node of $Y_i$ disappear ($|\Delta| - 1 = 0$), half-rounded nodes do not occur in a flat, and the formula is note 73's up to the terms in $\eta$ (checked numerically, Section 7). (vi) T1 is excluded: Lemma 2.1(c) needs the two children of a node to have independent slopes when both are tight with different directions, and note 75 shows $Q_4$ is false for T1.

## 6. The top condition

**Proposition 6.1 ($J = 0$: no condition; proved).** $T_0$ is the repetition code on the $2^r$ roots ($k_0 = 1$, $g_p = (1)$). A system on it has rows $\lambda_p \otimes 1$, so every solution has $\lambda_p^T M = 0$ and a genuine system is empty: $\mathrm{Top}_\Delta(0)$ holds for every $\Delta$. **Theorem 5.1 with $J = 0$ is a statement about the plain tree code with every twiddle uniform (T2) and nothing checked**; its price is the first-level term, $n_1 = 2^{r+1}$.

**Proposition 6.2 ($J = 1$; proved).** $T_1$ has rows $(1, t_x)$, $x \in P_1$ ($n_1 = 2^{r+1}$ points on a line). Assume the level-1 twiddles are pairwise distinct ($n_1$ field elements to compare; siblings are distinct by construction). Then (a) in a genuine system every direction is used at most once (two rows $\lambda \otimes (1, t)$, $\lambda \otimes (1, t')$ span $\lambda \otimes K^2$ and force $\lambda^T M = 0$); (b) $\mathrm{Top}_{\Delta_2}(0)$ and $\mathrm{Top}_{\Delta_3}(0)$ hold; (c) $\mathrm{Top}_{\Delta_4}(1)$ holds, and $\mathrm{Top}_{\Delta_4}(0)$ holds iff there are no six distinct level-1 twiddles $x_{ab}$, $0 \le a < b \le 3$, for which the rows $(e_a - e_b) \otimes (1, x_{ab})$ are dependent. *Proof of (b), (c).* For graphic directions a relation $\sum_{ab} c_{ab}(e_a - e_b) \otimes g_{ab} = 0$ reads, member by member, $\sum_{b} c_{ab}\, g_{ab} = 0$ for every vertex $a$ of the graph of used pairs (the equation of $a = 0$ is the sum of the others). Two vectors $(1, x), (1, x')$ with $x \ne x'$ are independent, so a vertex of degree 1 or 2 has $c = 0$ on its edges: the support of a relation is a subgraph of minimum degree 3. On three vertices there is none; on four it is $K_4$, and at each vertex the three vectors of $K^2$ have one relation up to a scalar, with nonzero coefficients, so $c_{01}$ determines all of $c$: the relation space has dimension at most 1. $\square$ The dependence in (c) is one polynomial equation in the six twiddles; by Desargues' theorem on the complete quadrilateral it says that the three pairs of opposite edges $\{x_{01}, x_{23}\}, \{x_{02}, x_{13}\}, \{x_{03}, x_{12}\}$ are in involution, that is, the three points $(x + x', x x')$ of $K^2$ are collinear (**checked numerically over GF($2^8$), Section 9, not re-proved here**; this is the configuration of note 75's counterexample to $Q_4$ for T1, where sibling pairs $\{a, a+1\}$ give $(1, a^2 + a)$, always collinear). So $\mathrm{Top}_{\Delta_4}(0)$ at $J = 1$ is "among the $\binom{n_1}{2}$ points $(x + x', xx')$ no three coming from disjoint pairs are collinear": $\binom{n_1}{2}^2$ operations by sorting directions, $1.4 \cdot 10^4$ at rate $2^{-3}$, $10^9$ at $2^{-7}$, $4 \cdot 10^{12}$ at $2^{-10}$. A random level 1 fails it with probability about $15\binom{n_1}{6}/q$: $2^{-47}$, $2^{-40}$, $2^{-22}$, $0.08$ at rates $2^{-3}, 2^{-4}, 2^{-7}, 2^{-10}$ (**estimated**).

**6.4 Mixing values of $J$ (proved).** Different $t$ can use different $J_t$ in one probability space: draw all twiddles as in T2, and let $\mathcal C$ be the conjunction of the conditions $\mathrm{Top}_{\Delta_t}(0)$ on $T_{J_t}$. For each fixed $T_{J_t}$ satisfying its condition the bad event of Theorem 5.1 has probability at most $p_t$, so $\Pr[\text{bad}_t \wedge \mathcal C] \le p_t$ and $\Pr[\bigcup_t \text{bad}_t \mid \mathcal C] \le \sum_t p_t/\Pr[\mathcal C]$: redrawing the top until the checks pass costs a factor $1/\Pr[\mathcal C]$, below 2 in the schedules used in Section 8.

(2) A *first-level part* $(\log_2(\mathcal L/p) + c_\kappa)/((64 - \lambda)n_{J+1})$, between $2.4/n_{J+1}$ (small $t$) and $2.8/n_{J+1}$ (large $t$ at low rates, where $\lambda$ is near 19 and $c_\kappa$ up to 14.8 bits): $0.150$ at rate $2^{-3}$ and $0.0099$ to $0.011$ at $2^{-7}$ for $J = 0$, halved by each checked level. It is intrinsic for unchecked levels (Section 6.3).

**Against the pigeonhole of note 77, Theorem 3.4 (guidance 3; computed, `scripts/84_pigeonhole.py`).** That theorem gives, for every MDS code over $K$, three codewords coinciding pairwise on $2k + \lfloor (k - 65)/63\rfloor$ leaves: an excess of at least $k/63 = 0.0159\,k$ over $2k - 1$, whatever the twiddles. Theorem 5.1 gives at most $\varepsilon_3 n$, whose main part is $0.32k$ to $0.34k$ at rate $2^{-3}$, $0.36k$ to $0.38k$ at $2^{-4}$, $0.49k$ to $0.51k$ at $2^{-7}$, $0.62k$ to $0.64k$ at $2^{-10}$ (plus the first-level part, $1.2k$ to $1.4k$ at $J = 0$ and $0.30k$ to $0.35k$ at $J = 2$). **Consistent, and a factor 20 to 40 above the proved lower bound.** The first-moment value for a uniformly random code (the largest $s$ with $\binom{n}{2k+s}3^{2k+s}q^{-(s+1)} \ge 2^{-130}$) is $0.16k$, $0.20k$, $0.32k$, $0.45k$ at the four rates: the main part is a factor $2.0$, $1.8$, $1.5$, $1.4$ above it. So the pigeonhole (one fixed pair $0, f$ and a subset sum) is far from what patterns with free supports allow, and the constant of Theorem 5.1 is within a factor 2 of what a union bound over patterns can give for any ensemble; the remaining factor is the price $\log_2\mathcal L + 1.44$ a tight leaf of the level structure (the same artifact as note 73's main term: Lemma 2.1 is blind to the nullity left). Which of the two (first moment or pigeonhole) is the truth for the tree code is **open**; I expect the first moment (**conjectured**).

## 8. The linear program with slack, and the list bound over $K$

**Proposition 8.1 (note 75's Lemma R1 and Proposition R2 with slack; proved).** Let $\mathcal J$ be a set of indices $j \ge 1$, $J^\circ = \max\mathcal J$, and suppose a code of length $n$ and dimension $\rho n$ has, for every $j \in \mathcal J$: any $j + 1$ distinct codewords coincide (at least two of them) on fewer than $(j\rho + \varepsilon_{j+1})n$ positions. Let $\tau^*_\varepsilon = \sup\{\mathbb E_\mu[\theta] : \mu \text{ a probability measure on } [0,1],\ \mathbb E_\mu[h_j(\theta)] \le j\rho + \varepsilon_{j+1},\ j \in \mathcal J\}$, $h_j(\theta) = \Pr[\mathrm{Bin}(j+1, \theta) \ge 2]$. If $M > J^\circ$ distinct codewords (symbols in any extension field) each agree with one word on at least $\tau n$ positions, then $\tau \le \tau^*_\varepsilon + (1 - \tau^*_\varepsilon)J^\circ/M$; so **at agreement $\tau^*_\varepsilon + \eta$ every list has at most $\max(J^\circ, J^\circ(1 - \tau^*_\varepsilon)/\eta)$ members.** *Proof.* Note 75, Section 4.1, verbatim with the right side $j\rho + \varepsilon_{j+1}$: for a sub-list $T$ of $j + 1$ members a position where two members of $T$ agree with the word is a coincidence position of $T$; averaging over sub-lists gives $\frac1n\sum_x H_j(c_x; M) \le j\rho + \varepsilon_{j+1}$ (hypergeometric); R1 ($H_j(c; M) \ge h_j((c - J^\circ)/(M - J^\circ))$ for $j \le J^\circ \le c$) turns it into the binomial constraint for $\theta'_x = \max(0, (c_x - J^\circ)/(M - J^\circ))$, and $c_x/M \le J^\circ/M + (1 - J^\circ/M)\theta'_x$. $\square$ A dual certificate $\lambda_0 + \sum_j\lambda_j h_j(\theta) \ge \theta$ on $[0,1]$ gives $\tau^*_\varepsilon \le \lambda_0 + \sum_j\lambda_j(j\rho + \varepsilon_{j+1})$: **the slack costs $\sum_j\lambda_j\varepsilon_{j+1}$**, and constraints can be dropped freely.

**Theorem 8.2 (list bound over $K$; proved, the numbers computed with certificates).** Plain tree code T2, twiddles uniform in $K = \mathrm{GF}(2^{64})$, $n = 2^{20}$ to $2^{24}$.
