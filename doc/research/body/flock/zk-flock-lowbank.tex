\subsection{A long-chain repair for the low query region}\label{note:zk-flock-lowbank}

\paragraph{Result.} The same $3840$ long-chain cycles jointly hide one sixteen-point low coset and one thirty-two-point high coset of lane $59$, together with the established terminal, final-child, Flock and memory/root interface, below $2^{-151}$. The complete $4096$-point public prefix can also be retained with its actual correlated law. An old count bank masks the terminal claim first; the new bank then masks the raw values, avoiding the former Moore loss. Public heights and verifier equations are unchanged. Retaining all $8192$ public-prefix points would instead leak in the fixed-completion model. Arbitrary query families, common completion and the other full-view obligations remain open.

\subsubsection{An explicit low-coordinate source}

Start with the wider library of \noteref{zk-flock-children}. Among physical BLAKE2s positions below $2^{14}$, select every aligned sixteen-row block whose rows are outside that library, the mandatory binary source and the five protected general-input positions. There are exactly $240$ such blocks; their bases are below $12288$. Sort the $56$ bases whose bit four is zero and separately the $184$ whose bit four is one. Pair the former with the first $56$ of the latter, then pair the remaining lower $64$ with the remaining upper $64$. Enumerate these $120$ pairs in that order as $\zkLowPairs=\{(u_j,v_j):0\le j<120\}$. The only other free low positions are $437,438,439$, which remain unused. This public balanced matching replaces the earlier sorted-half matching discussed below; it uses exactly the same rows.

Use one fresh $32$-cell frame at exponent $1280+32\cdot65535$, compression code location $1090$ and its closing return at $1091$. The frame and code are disjoint from the earlier libraries. Repeatedly execute the same baseline compression/return cycle, with return controls at offsets $16,17,18$. For pair number $n=16j+t$, place its two compressions at $u_j+t,v_j+t$, for $t<16$. Each of the ten compression count columns then has labels $\gen^{2n},\gen^{2n+1}$. Independently swap these two labels in every column. The $3840$ reads of each operand and code location form one complete chain; the return rows and their labels remain fixed. All choices preserve every local constraint, bus multiset, count-column product, memory image and compression witness.

The bank replaces $3840$ general-input positions, leaving $57608$, and adds two code locations for a total of $64$. Sharing one frame instead of $3840$ distinct frames leaves at most $177413$ Flock padding frames, or $5677216$ cells. The remaining cell count permits at most $26960$ slots of size $256$ before accounting for fragmentation. The explicit allocation in Section~\ref{sec:zk-flock-reservation} leaves $26959$ wholly free aligned slots. These are reservations for the same public height profile, not a completed common-sampler theorem.

\subsubsection{Independent masks for the low values and terminal count}

For $x+\subsp_4\subseteq\subsp_{18}\setminus\subsp_{13}$, only the $\mathsf{cnt\_cv1}$ block contributes changing lane-$59$ values. A new-bank swap in child slot $t$ contributes to its coefficient coordinate the scalar $\gen^{2t}\zkLowWeights_j(x)$, where
\[
 \zkLowWeights_j(x)=(1+\gen)\gen^{32j}
       \bigl(\novel_{u_j}(x)+\novel_{v_j}(x)\bigr).
\]
Pairs $j<32$ touch positions below $4096$; both endpoints of every remaining pair are at least $4096$. The native exhaustive certificate proves binary rank $64$ for the $88$ scalars with $j\ge32$, at all $32256$ sixteen-point cosets in $\subsp_{19}\setminus\subsp_{13}$, and checks the same restricted polynomial through the actual additive NTT. Independent slot bits therefore supply sixteen exact base-field uniforms while preserving the complete prefix $\subsp_{12}$. Keep the original factors $\gen^{32j}$ after removing pairs; the read labels are not renumbered.

The terminal $\mathsf{cnt\_cv1}$ claim need not use the same new bits. In the old core's child-zero count bank, the low raw contribution is determined by two base-field scalars: its equal coefficient increments on $(0,4)$ and $(8,12)$. Retain these $128$ bits together with the $48$ old count bits whose physical positions are below $4096$. This fixed map has binary rank at most $176$ and is independent of the later terminal extension point. Choose a basis of its image if its coordinates are dependent. Theorem~\ref{thm:dense-fixed-observation-span}, with budget $176$, makes the terminal count uniform on every such fiber, except with probability $\zkDenseError{176}$. Its normalized weights have the dense twelve-coordinate support; the old selector exclusions keep the common output factor nonzero. No earlier child evaluation is retained here, because the child-plane coordinates will already be uniform.

Use this old terminal mask first, retaining its actual low raw contribution. Then use the new bank's $88$ unexposed pairs to hide all sixteen low values; their terminal translation is absorbed by the preceding uniform. The two stages use disjoint bits and both fix the prefix. This replaces the former Moore-determinant argument with a smaller fixed-disclosure budget and an exact raw-query span.

\subsubsection{Joint composition with the actual children}

\begin{theorem}[The repaired low-coset boundary]\label{thm:zk-lowbank-interface}
Add this bank to the wider source, with a common valid completion respecting its disjoint reservation. All thirty-seven BLAKE2s terminal claims, twelve actual final GKR children, established Flock endpoints and all sixteen lane-$59$ values in one coset inside $\subsp_{18}\setminus\subsp_{13}$ have a joint witness-free simulator. Including the complete memory envelope and shared bus root, its error is below $2^{-151}$. The coset may be selected using only honest query indices.
\end{theorem}
\begin{proof}
Keep the good-coin ledger of Theorem~\ref{thm:zk-flock-twelve-interface}, using an auxiliary high coset solely for its old span events. First use the old count banks with $\mathsf{cnt\_cv1}$ excluded. They hide the other nine terminal counts and the two count-plane directions in each child, without changing any low raw value or terminal $\mathsf{cnt\_cv1}$. The nonzero degree-$20$ pull/count minor for $\mathsf{cnt\_cv0},\mathsf{cnt\_out0}$ has block indices $(190,192)$ and $(48,50)$ respectively. Charge another $20/2^{192}$, conservatively retaining the old minor term. These masks leave each residual $P_t+\gen Q_t$ fixed.

Next apply the independent old-terminal and new-query replacements just proved. Both change only terminal $\mathsf{cnt\_cv1}$, low raw values and coordinates already uniform in the count planes; their residual and program/frame projections vanish. Finally the old operand/frame/PC sources hide the nine program/frame coordinates and four residuals. All their translations of already uniform coordinates are absorbed.

Complete the memory/root and compression-value/Flock hybrids in their established order. Every metadata choice preserves the required multisets and Flock witness. Add $\zkDenseError{176}$ and $20/2^{192}$ to the old ledger and memory/root term. Exact rational arithmetic gives the stated bound, uniformly in the selected coset and every fixed complement. The proof uses conditional fibers, not conditioning of an unconditional marginal theorem on later disclosures.
\end{proof}

\subsubsection{Two adjacent sixteen-point cosets jointly}

Fix $x+\subsp_5\subseteq\gen^{18}+\subsp_{18}$ and put
\[
 \zkThirtyTwoLow{d}=\sum_j f_{32j+d}\novel_{32j}(x),\qquad d<32.
\]
The thirty-two raw values are an invertible evaluation map of these coefficients. The block weights are one for $\mathsf{cnt\_cv1}$ and $\mathsf{cnt\_out0}$ and zero for the other changing blocks. All old non-count metadata changes cancel on this region. Core swaps fill the pairs $(c+16+8b,c+20+8b)$; wider swaps fill $(c+4b,c+4b+8)$, for $c<4,b<2$. Their sixteen independent kernel coordinates leave the following sixteen quotients fixed:
\[
 \begin{aligned}
 \zkThirtyTwoLower{c}{b}&=\zkThirtyTwoLow{c+4b}+\zkThirtyTwoLow{c+4b+8},\\
 \zkThirtyTwoUpper{c}{b}&=\zkThirtyTwoLow{16+c+8b}+\zkThirtyTwoLow{20+c+8b}.
 \end{aligned}
\]
The two halves of each core or wider bank have the same rank-$64$ scalar maps already certified in \noteref{zk-flock-sixteen}, with the core map rescaled by the nonzero factor $\novel_{16}(x)^{-1}$. Thus their joint raw image is precisely the $16$-dimensional kernel of this quotient map over $\K$.

For the balanced new bank define
\[
 \begin{aligned}
 \zkBalancedLowWeight{j}&=(1+\gen)\gen^{32j}\novel_{u_j}(x),&&j<56,\\
 \zkBalancedHighWeight{j}&=(1+\gen)\gen^{32j}
       \bigl(\novel_{u_j-16}(x)+\novel_{v_j-16}(x)\bigr),&&56\le j<120.
 \end{aligned}
\]
The native exhaustive certificate proves, at every one of the $8192$ cosets in this region,
\[
 \begin{aligned}
 \operatorname{span}_{\Ftwo}\{\zkBalancedLowWeight{j},\gen^{16}\zkBalancedLowWeight{j}:j<56\}&=\K,\\
 \operatorname{span}_{\Ftwo}\{\zkBalancedHighWeight{j},\gen^8\zkBalancedHighWeight{j}:56\le j<120\}&=\K.
 \end{aligned}
\]
These are fixed query maps, not assertions about random extension points.

\begin{theorem}[Thirty-two high-region values with the VM boundary]\label{thm:zk-highbank-interface}
Under the same common-completion assumptions, all thirty-two raw lane-$59$ values in one coset inside $\gen^{18}+\subsp_{18}$ join the established terminal, final-child and Flock interface below $2^{-155}$, or below $2^{-151}$ including memory and the shared root. No additional rows, error terms or verifier equations are needed.
\end{theorem}
\begin{proof}
Condition on all new-bank bits. The core replacement in Theorem~\ref{thm:zk-flock-twelve-interface} hides nineteen terminal metadata fields, twelve final GKR children and two upper kernel coordinates per child. Removing the nonzero factor $\novel_{16}(x)$ from its fixed query map changes neither the $128$-bit disclosure budget nor the $320$-bit joint budget with the earlier extension evaluation. Retain the sixteen lower coefficients and eight upper pair sums during this replacement, not the changing partners of the upper kernel coordinates. The two disjoint halves of each wider bank then fill two lower kernel coordinates, instead of only their sum. Each scalar map is onto, and all its terminal/child translations are absorbed by the first replacement. We have obtained sixteen independent kernel uniforms and the replaced boundary, while retaining the sixteen quotients and every new bit.

Use only the new $\mathsf{cnt\_cv1}$ bits; condition on the other new columns. For $j\ge56$, both endpoints have bit four set, so these swaps change no lower coefficient. Slots $t=c,c+4$ jointly fill $\zkThirtyTwoUpper{c}{0}$ using the second scalar span above; slots $t=c+8,c+12$ independently fill $\zkThirtyTwoUpper{c}{1}$. All eight upper quotients therefore become uniform while the lower quotients remain fixed.

Now use $j<56$. The left endpoint has bit four zero and the right endpoint has it set. Slots $t=c,c+8$ jointly fill $\zkThirtyTwoLower{c}{0}$ by the first scalar span; slots $t=c+4,c+12$ independently fill $\zkThirtyTwoLower{c}{1}$. Their upper, kernel and terminal/child changes are absorbed by the preceding uniforms. The two stages use disjoint pairs, and within each stage every displayed quotient uses disjoint slot bits. Thus all thirty-two coefficient coordinates and the preceding boundary are jointly uniform. Evaluate, discard the auxiliary bits and complete the established memory/root and compression-value/Flock hybrids. Both quotient replacements are exact, so the old error ledger is unchanged.
\end{proof}

Together with Theorem~\ref{thm:zk-lowbank-interface}, this also hides one entire sixteen-point coset chosen anywhere in $\subsp_{19}\setminus\subsp_{13}$ below $2^{-151}$. Select the corresponding simulator using the public query indices and discard unneeded high-region values. This argument treats the low and high cases as alternatives; the following theorem supplies a simultaneous view. No thirteen-query occupancy exception is needed for a selected high-region coset after this repair.

\subsubsection{A low coset and a high coset simultaneously}

\begin{theorem}[A split-region forty-eight-value boundary]\label{thm:zk-split-region-interface}
Under the same common-completion assumptions, jointly include one sixteen-point coset inside $\subsp_{18}\setminus\subsp_{13}$ and one thirty-two-point coset inside $\gen^{18}+\subsp_{18}$. Together with the established terminal, final-child, Flock and memory/root interface, this view has a witness-free simulator below $2^{-151}$. Both cosets may be selected using only honest query indices. The source, public heights and low-theorem error ledger are unchanged.
\end{theorem}
\begin{proof}
The count columns separate the regions: $\mathsf{cnt\_out0}$ has zero encoder weight throughout the low region and weight one throughout the high region; $\mathsf{cnt\_cv1}$ has weight one in both. Their swap bits are independent.

First use all old core and wider count banks except $\mathsf{cnt\_cv1}$, together with the new $\mathsf{cnt\_out0}$ bits. Their projection fills $\E^{17}\times\K^{32}$: nine terminal counts, eight child-plane coordinates and thirty-two high values. Repeat the count-only high-region proof with $\mathsf{cnt\_out0}$ last in every core bank. Its count and query maps match those previously used for $\mathsf{cnt\_cv1}$, so the $128$- and $320$-bit budgets are unchanged. Use the same additional $\mathsf{cnt\_cv0},\mathsf{cnt\_out0}$ minor. Wider $\mathsf{cnt\_out0}$ bits fill the lower kernel coordinates; new $\mathsf{cnt\_out0}$ bits fill the sixteen quotients. Their terminal and child translations are absorbed by the core uniforms. This group fixes all low values, terminal $\mathsf{cnt\_cv1}$, the program/frame fields and the four residuals.

Now use old core $\mathsf{cnt\_cv1}$ bits to hide its terminal count while retaining its two low raw coefficients and prefix bits, then the new $\mathsf{cnt\_cv1}$ bits to hide the low sixteen-value vector. The first replacement costs $\zkDenseError{176}$; the second is exact. Their high and child-plane translations are absorbed. Finally use the operand/frame/PC sources for the thirteen remaining extension coordinates. The four conditional dimensions are $5312$, $192$, $1024$ and $2496$, totaling $9024=31\cdot192+48\cdot64$.

Apply the established memory/root and compression-value/Flock hybrids. Use the actual high coset in the old good-coin ledger instead of an auxiliary one; every bound is uniform in it. Shared extension coins require no independence of bad events: their union has the same bounded total. Each stage uses disjoint source bits. Honest-query selection and discarding unqueried values preserve the bound.
\end{proof}

This is a cross-region theorem, not arbitrary multi-coset coverage. Proposition~\ref{prop:zk-scattered-support} exhibits a dispersed forty-two-point dependency of this source inside an event below $2^{-266}$ at rate one. The complete exceptional family remains unbounded.

\subsubsection{Retaining the complete $4096$-point public prefix}

\begin{theorem}[The complete prefix and split-region boundary]\label{thm:zk-prefix-split-interface}
Assume also the public count-prefix contract of \noteref{zk-flock-query-fiber}. Theorem~\ref{thm:zk-split-region-interface} remains true after including every lane-$59$ value on $\subsp_{12}$, with its actual correlated distribution, below $2^{-151}$. No additional source or row is needed.
\end{theorem}
\begin{proof}
Exactly $1084$ source bits reach this prefix: $384$ old core/wider $\mathsf{cnt\_cv1}$ bits, $188$ PC bits and $512$ new $\mathsf{cnt\_cv1}$ bits. Their truncated coefficient supports are nonempty and disjoint, with known nonzero coefficients. Evaluation on $\subsp_{12}$ is injective on polynomials of degree below $4096$. The full prefix therefore encodes these $1084$ fair bits exactly, plus its computable public baseline; it is not a vector of independent base-field uniforms.

Each PC bank exposes the $47$ indices in $\{16j:0\le j<48\}\setminus\{192\}$. Together with the already absent index $192$, retain $48$ bits. The dense lemma with budget $48$ supplies the earlier residual evaluation on every such fiber. In bank zero, retain that earlier $192$-bit evaluation as well when hiding the terminal PC value, using budget $240$. Both free-coordinate maps and index sets are common to the four banks, so each good-coin event is charged once. Existing selector exclusions suffice. Conservatively add $\zkDenseError{48}+\zkDenseError{240}$ to the preceding ledger.

Condition on all $1084$ prefix bits. The other-count group is zero on $\subsp_{18}$. The old terminal-count replacement already retains its $48$ visible bits and low raw contribution; the new low-query replacement uses only the $88$ pairs whose endpoints are at least $4096$. Both therefore fix the prefix. The remaining operand/frame/PC group hides its thirteen extension coordinates while fixing the prefix by the new erasure argument. All changes to earlier uniforms are absorbed. Thus the $31$ metadata/child fields and $48$ selected raw values are uniform independently of the prefix bits on good coins.

Sample those $1084$ fair bits to reconstruct the prefix, and perform the established memory/root and compression-value/Flock hybrids. The retained prefix law is public and independent of the complementary private data. Exact rational arithmetic bounds the old ledger, memory/root term, extra minor and three new dense terms
\[
 \zkDenseError{176}+\zkDenseError{48}+\zkDenseError{240}
\]
together below $2^{-151}$. The bound is uniform in both selected cosets and every prefix value in its support.
\end{proof}

\begin{proposition}[An unsafe larger prefix envelope]\label{prop:zk-full-prefix-envelope}
For the fixed-completion private-pointer witnesses of \noteref{zk-flock-query-fiber}, the entire prefix $\subsp_{13}$ together with the six lane values at $12290,\ldots,12295$ has disjoint laws. No common simulator for this envelope has error below $1/2$ for both witnesses.
\end{proposition}
\begin{proof}
The $8192$ prefix values determine $2492$ metadata bits, because their nonzero truncated coefficient supports are disjoint. Fixing that prefix therefore leaves exactly the source directions with all indices at least $8192$. On $\subsp_{14}$, truncating their higher zero terms leaves $384$ distinct polynomials.

The native certificate in \auditref{zk_flock_lowbank_audit.py}, run with \texttt{--prefix-limit}, gives rank $382$ on these six points and a binary functional detecting the private-pointer shift. All six five-point deletions have full rank $320$. The shift is zero on $\subsp_{13}$, so both witnesses have the same prefix law but disjoint conditional six-value supports. Their joint laws have distance one; the simulator lower bound follows by the triangle inequality.
\end{proof}

This is not an impossibility result for the actual honest query distribution: it relies on overdisclosing every prefix point. The remaining proof must retain the actual prefix queries jointly, rather than treating their witness-independent marginal as permission to reveal the entire region.

Even the $4096$-point prefix cannot be appended to arbitrary low-query envelopes for free. Fixing its $1084$ bits leaves $1792$ distinct nonzero source polynomials on $\subsp_{14}$. The same audit certifies rank $1530$ on $12288,\ldots,12311$, a separating private-pointer functional, and full rank $1472$ after each one-point deletion. Thus these twenty-four values have disjoint conditional witness laws, although the proved sixteen-value boundary remains valid. The probability that any low-region thirty-two-point coset receives twenty-four distinct honest queries is at most $7936\binom{32}{24}q(q-1)\cdots(q-23)/D^{24}$, below $2^{-329},2^{-379},2^{-419},2^{-455}$ at rates one through four, with $D=2^{22+\rexp}$. This safely bounds the displayed concentration event, not every defect after prefix conditioning.

\paragraph{Why the original matching needed replacement.} The earlier rule paired the lower $120$ sorted bases with the upper $120$. Exactly $30$ pairs then touched a base whose bit four was zero. On a high-region thirty-two-point coset, every old source fixes the eight lower quotients displayed above. Each receives contributions from only two slot families of $30$ bits; the equally weighted two count columns give the same directions, not twice the rank. Their joint binary rank is therefore at most $8\cdot60$, instead of $8\cdot64$. The full raw rank is at most $2016$, and the native check attains this bound at $x=\gen^{18}$. Reordering the old pair labels cannot fix this dimension deficit. The balanced matching uses all $56$ lower bases in distinct cross-half pairs and removes that obstruction.

For the original matching, the twenty-eight points $12288,\ldots,12315$ also give raw rank $1760$ out of $1792$ and a functional separating the private-pointer difference. Its first twenty-seven points have full rank $1728$; the complete thirty-two-point block has rank $1760$. The audit preserves this historical regression and checks that the balanced source fills the displayed low thirty-two-point view. There are $7936$ cosets of $\subsp_5$ in $\subsp_{18}\setminus\subsp_{13}$. For independent honest queries, the probability that any one receives at least twenty-eight distinct queried points is at most
\[
 7936\binom{32}{28}\frac{q(q-1)\cdots(q-27)}{D^{28}},
 \qquad D=2^{22+\rexp}.
\]
This is below $2^{-399},2^{-458},2^{-505},2^{-548}$ at rates one through four. The union bound chooses the coset, its twenty-eight distinct points and distinct query positions hitting them. It bounds this concentration event, not all rank defects of either matching. No theorem yet forces an arbitrary distinguishing query set to have this concentration.

\paragraph{Evidence and boundary.} \auditref{zk_flock_lowbank_audit.py} checks all $32256$ sixteen-point scalar maps after retaining the $4096$-point prefix and both high-region quotient spans at all $8192$ cosets. Its default run checks the old terminal's conditional rank and exact error ledger; \texttt{--full} also checks complete chains and the historical, dispersed and overdisclosure regressions. The full-query audit accepts \texttt{--joint-boundary --lowbank --public-prefix-log 12}; smaller prefix logs $9,10,11$ remain supported. For low points $12288,\ldots,12303$ and high points $262144,\ldots,262175$, it certifies total rank $10108$, prefix rank $1084$ and full fiber rank $9024$. It also checks the four prefix-preserving projections, including the old terminal fiber after retaining its raw map. These sampled extension-field checks support the algebra; the preceding proofs supply the uniform bounds. Arbitrary query families, other lanes and PCS stages, omitted GKR/table/Flock messages, authentication and one common valid sampler remain unproved.
