\section{Source map and audit conventions}\label{sec:zk-index}

Every former standalone note is included in this PDF. The map below preserves its filename as a lookup key; links lead to the corresponding section, not to a separate PDF. The former \nolinkurl{zk-padding.tex} overview is now Sections~\ref{sec:zk-goal}, \ref{sec:zk-remaining} and~\ref{sec:zk-status}. Bibliographies and document setup are shared.

\subsubsection*{Audit sources.} Python audits and their local helper modules live in \path{doc/research/audits/}. An audit link in a proof opens that source relative to this PDF's location in \path{doc/research/.build/}. Run unqualified commands in the detailed notes from the audit directory; from the repository root, prefix the script with \path{doc/research/audits/}. The native memory-prefix example is in \path{crates/lean_vm/examples/zk_memory_prefix_audit.rs} and is run in release mode. The source checker verifies the local Python import closure, but does not rerun every experiment or certify the mathematics.
