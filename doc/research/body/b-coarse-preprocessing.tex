\section{Coarse GKR and the optional public-preprocessing branch}\label{sec:coarse-preprocessing}

These notes isolate the bytecode residual and develop a conditional route through public random libraries. The strongest results here assume additional public preprocessing and native field-valued frame/offset support that is not implemented. This branch is not adopted by the baseline proof plan; using it requires an explicit change to that plan's model and completion construction.
