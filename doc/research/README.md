# Statistical ZK research

The entry point is [main.tex](main.tex). It builds one document containing the target definition, remaining proof plan, current results and all supporting notes. The target is honest-verifier statistical ZK with total distance at most `2^-128`; full ZK is not yet proved.

```bash
cd doc/research
latexmk -pdf main.tex
python3 check.py
```

The PDF is `.build/main.pdf`. Read `body/01-target.tex`, `body/02-proof-plan.tex` and `body/03-status.tex` first. Supporting proofs are grouped under `body/`; the appendices separate count-tree history and the optional public-preprocessing branch. `body/c-source-map.tex` maps the former standalone filenames to internal sections. All note references are internal PDF links, and references are collected in `references.tex`.

For canonical raw aggregation leaves, the new [leaf-probe note](body/foundations/zk-leaf-probes.tex) reduces private prefix counts to eight addresses. Public coverage geometry fixes the other probes, and optional frame-local DEREF filler removes its count-zero contribution without adding rows. Eight shared helper frames and exactly 230 DEREF/JUMP cycles per 42-digit word make the entire prefix count vector public. Run `python3 doc/research/audits/zk_leaf_probe_audit.py` for exact target-sum maxima and complete counted-bus certificates. The native leaf allocation audit now checks the public profile for XMSS, SPHINCS and mixed leaves; `--prove` verifies the changed bytecode digest too. This requires externally public signer geometry. Helper normalization, common capacity, recursive children and full statistical ZK remain unproved.

Small frames now have a proved limitation: with all padding frames outside the public prefix, two private alternatives each requiring more than half the available prefix-read budget remain distinguishable at PCS query zero under every randomized completion. A public probe-load bound or different prefix-access policy is necessary. Separately, the stronger envelope revealing the whole count prefix can be impossible even for nine ordinary range checks; that is not a sparse-query attack. Both results are in the [memory note](body/foundations/zk-memory-frames.tex). Run `python3 doc/research/audits/zk_memory_probe_prefix_audit.py --count-budget` for exact bounds and cycle certificates, and `cargo run --release -p lean_vm --features zk-research --example zk_memory_probe_prefix_audit -- --count-budget` for two native proofs, separate authenticated projections and two large-code executions. Neither result rules out a suitably capacity-restricted aggregation profile.

The [memory note](body/foundations/zk-memory-frames.tex) isolates a further count exposure: public range-probe values do not hide their final read counts. At the candidate layout, initial query zero in lane 40 exposes the count of memory cell zero; value-only padding leaves error floors above `2^-17` through `2^-22` across the four rates. Fixed-cost real/dummy reads repair a chosen count prefix. The [count note](body/counts/zk-count-columns.tex) now normalizes the transferred helper uncertainty jointly with all 28 column products without adding or relabeling compression rows. Once XOR/SET products are public, this uses only MUL/DEREF/JUMP additions; otherwise a noncompression preprocessing stage handles them too. Both require sufficient disjoint capacity. Run `python3 doc/research/audits/zk_memory_probe_prefix_audit.py --count-products` for joint certificates including all 27 bounded access patterns with privately varying totals, or `--count-prefix` for the original obstruction and cycle repair. The native `cargo run --release -p lean_vm --features zk-research --example zk_memory_probe_prefix_audit -- --count-prefix` verifies four proofs plus separate authenticated encoder projections. The public count coordinates join the memory/root marginal below `2^-151`; the full-prefix budget, intermediate GKR and arbitrary count queries remain open. This is not full ZK.

The immediate obstruction is [the frozen count frontier](body/counts/zk-count-frontier.tex). The balanced source preserves every aligned `2^14`-leaf count product. Two private-pointer gadgets have the same 28 column products but different frontier nodes, exposed by the sixth GKR packet with almost unit distinguishing probability. Localization can fix that coarse frontier, but a second valid pair inside one 256-row interval still leaks through packet eleven's count child zero. Run `python3 doc/research/audits/zk_count_frontier_audit.py --native` for both valid-cycle/reference-prefix certificates and two complete native small-frame witness proofs. These results reject specific fixed completions, not every padding-based approach.

[In-frame count adapters](body/counts/zk-count-adapter.tex) repair the later child: 3072 zero-multiplication rows in existing frames provide 1536 independent label trades, with no new compression rows or verifier equations. Their conditional span error is below `2^-160`; this child joins the established restricted boundary below `2^-151`, retaining the full 4096-point prefix, now encoding 1116 bits. Run `python3 doc/research/audits/zk_count_adapter_audit.py --full` for all cycle checks, exact error bounds and native-field rank. The earlier coarse obstruction remains, and the enlarged projection excludes intervening GKR messages and the new MUL disclosures. Next complete a capacity-checked public coarse frontier and a joint all-layer count/fingerprint proof, not just independent child marginals.

The [count-normalization note](body/counts/zk-count-columns.tex) makes all sixteen coarse BLAKE2s bytecode-count products public for the full 65536-row private budget. Unequal-center repetitions reuse 95112 mandatory rows; real-row sorting and exact label routing balance their coarse products. No random-choice bits, frames or general-input positions are removed. Run `python3 doc/research/audits/zk_count_reuse_audit.py --full` for the exact budget, native layout, complete label assignments, cycle checks and shared Flock-side row/frame/code reservation. It leaves 26959 fully free aligned 256-cell slots; the former 26960 figure was only a cell-count ceiling.

The [load-bounded memory-count repair](body/counts/zk-memory-count-coarse.tex) fixes all nine remaining BLAKE2s coarse columns using a shared frame and ordinary XOR self-copies. Its stronger 32-label router supports 256 BLAKE2s accesses per real cell with 149319 XOR rows and 16591 extra returns, reusing 512 general-input compressions. Relocating one already-erased low-bank block preserves the restricted privacy theorem below `2^-151`, with 1117 prefix bits. Run `python3 doc/research/audits/zk_memory_count_coarse_audit.py` for both router variants, valid cycles, multi-slot allocation and exhaustive span checks. Run `cargo run --release -p rec_aggregation --example zk_frame_load_audit` to check the aggregation guest's static read cap under the fresh-frame contract. Large frames may occupy consecutive free slots; small frames alone do not bound repeated reads. The public entry point, larger code image, total allocation and integration with the range-probe repair below still need a common sampler. The other 18 count columns, full transcript and opening proofs remain open; uncertainty is transferred to XOR, not eliminated globally.

The [memory note](body/foundations/zk-memory-frames.tex) proves a range-probe-compatible variant: keep the first 65536 words public, and move the segment-zero mask bank and payload beyond them. The ordinary range-check instructions remain unchanged. The [count note](body/counts/zk-memory-count-coarse.tex) now carries the established restricted joint interface through this relocation, including the memory envelope and shared root below `2^-151`. The candidate layout loses 256 free slots, leaving 26703 before fragmentation. Run `python3 doc/research/audits/zk_memory_probe_prefix_audit.py --relocated-library` for the shifted-mask, mixed-PCS and full metadata-library certificates, and `cargo run --release -p lean_vm --example zk_memory_probe_prefix_audit` for a public-bootstrap fixture, seven range inputs, two complete proofs and the native NTT identity. A general compiler/allocator transformation, larger code reservation and full joint transcript remain open; this is not a full-VM theorem.

The [larger-code corollary](body/counts/zk-memory-count-coarse.tex) extends the restricted interface to the native aggregation guest's bytecode log 19. Both old GKR count minors vanish in this layout; two replacement minors restore their degree-20 bounds. The prefix now contains 1085 fair bits and the restricted joint error stays below `2^-151`. The 99 padding instructions fit in unused code space after a fixed public translation; installing them would change the public bytecode and digest. Run `python3 doc/research/audits/zk_large_code_audit.py --full` for relocated valid cycles, actual source maps, the selected joint fiber and exhaustive erased query spans. This closes a code-height compatibility gap, not the general allocator, common sampler or full transcript proof.

The [memory note](body/foundations/zk-memory-frames.tex) now gives a public entry wrapper and an operational relocation theorem under an explicit address discipline and allocation budget. The opt-in `zk-research` Cargo feature implements next-fit allocation in public intervals for static/runtime hints and filler frames. Run `cargo run --release -p lean_vm --features zk-research --example zk_allocator_audit` for the private-branch fixture and two same-statement native proofs. The actual wrapped aggregation guest now passes code-height/read-cap checks and leaf audits for both schemes: `cargo run --release -p rec_aggregation --features zk-research --example zk_guest_allocation_audit -- 453 0` checks a substantial XMSS witness against the candidate reservation; `-- 6 1` checks a mixed leaf, and `-- 1 0 --prove` also verifies a native proof under the wrapped program's own digest. The audit checks requested-object access safety, unused masks, frame/instruction correspondence and unchanged compression data. Default allocation and all verifier equations are unchanged. A public resource theorem and pointer-discipline certificate for all supported witnesses, including recursive children, plus the common ZK padding sampler remain necessary. The feature does not produce ZK proofs, and the private diagnostic traces are not public inputs.

The earlier joint theorem in [body/flock/zk-flock-sixteen.tex](body/flock/zk-flock-sixteen.tex) covers any twelve lane-59 values in one specified sixteen-point encoder coset, all twelve final GKR children and the established terminal/Flock interface, below `2^-155`, or `2^-151` including memory and the shared root. It assumes a common valid completion and does not cover multiple cosets or the full transcript. Its source is specified in [body/flock/zk-flock-children.tex](body/flock/zk-flock-children.tex). Run `python3 doc/research/audits/zk_flock_multicoset_audit.py` for the exact dual identity, binary-source geometry and error bounds, and `python3 doc/research/audits/zk_flock_children_audit.py --full --wide` for complete source validity, joint ranks and exhaustive native query maps.

The subsequent [balanced long-chain repair](body/flock/zk-flock-lowbank.tex) uses 3840 cycles and jointly hides one sixteen-point low coset and one thirty-two-point high coset with the established VM/memory/root interface, below `2^-151`, even while retaining all 4096 public-prefix values with their actual correlations. Disjoint old-terminal and new-query masks remove the former Moore loss; retaining 188 exposed PC bits needs no extra rows. The native audit has rank 10108, public-prefix rank 1084 and full remaining fiber rank `9024/9024`. Add `--public-prefix-log 12` to the joint multicoset audit for this exact prefix encoding. Run `python3 doc/research/audits/zk_flock_lowbank_audit.py --full` for valid read chains, exhaustive native query maps and exact ledgers. Its `--prefix-limit` mode proves that retaining all 8192 prefix values would instead reveal a six-query private-pointer distinguisher: this rules out that enlarged envelope, not the actual honest-query target. Common completion and the public-prefix contract remain assumed; arbitrary queries and the full opening remain unproved.

Without this extra bank, [body/flock/zk-flock-query-fiber.tex](body/flock/zk-flock-query-fiber.tex) gives a six-query obstruction excluding 128-bit privacy at all four rates. The default multicoset audit preserves that negative regression. Use `--query-map --joint-boundary --lowbank` to diagnose the enlarged source with all initial lane-59 queries and terminal/GKR fields; `--include-low` retains public-prefix observations. The successful sampled ranks are not a uniform statistical bound.

The original long-chain matching admitted a concentrated twenty-eight-query distinguisher and a structural thirty-two-point rank deficit. The balanced matching repairs those tests but has a certified minimal raw dependency on 42 points in different sixteen-point cosets. The complete noise code on that low band has binary dimension 2688. All events with at least 42 queries anywhere in the band cost less than `2^-266` at rate one; smaller and cross-band dependencies remain unbounded. Run `python3 doc/research/audits/zk_flock_lowbank_audit.py --scattered` for the whole-band coefficient certificate, native minimal-support check and exact rarity bounds. The [query-family note](body/flock/zk-flock-query-fiber.tex) explains why counting only concentrated small-coset events cannot finish the proof.

`preamble/` centralizes document setup and loads the VM's shared notation from `../leanvm/preamble/macros.tex`. There is one build directory and one document root. Do not restore independent document wrappers around body files.

Python audits live together in `audits/`, preserving their local imports. Run a named audit from that directory, for example:

```bash
cd audits
python3 zk_four_round_tail_audit.py
```

Alternatively, from the repository root use `python3 doc/research/audits/zk_four_round_tail_audit.py`. Unqualified audit commands in the detailed notes assume the `audits/` working directory. The audit helper loads the actual `python-verifier/verifier.py` from the repository. Full-support count-head modes are expensive and are not part of the quick structural check. Exact rank certificates and successful verifier replays are evidence for their stated lemmas, not an end-to-end privacy proof.

[body/10-wire-ledger.tex](body/10-wire-ledger.tex) inventories the current wire and exact committed-size budget. [body/flock/zk-flock-interface.tex](body/flock/zk-flock-interface.tex) proves that pinned-IV padding also leaks through directly disclosed table columns, even with row shuffling. A new three-point source and general compression inputs jointly hide all eighteen BLAKE2s value claims with the established endpoints. Run `python3 doc/research/audits/zk_three_point_audit.py` and `python3 doc/research/audits/zk_flock_interface_audit.py` for the certificates, or `cargo run --release -p lean_vm --example zk_flock_interface_audit` for two complete small-frame VM proofs whose scalar streams exhibit the invariant. The candidate varies message, chaining value and metadata, not merely the message profile. Middle rounds and full opening remain unproved.

[body/flock/zk-flock-columns.tex](body/flock/zk-flock-columns.tex) extends that joint theorem to all thirty-seven BLAKE2s terminal columns, below `2^-156`. A disjoint library of equal-compression pairs supplies metadata randomness while preserving the packed witness pointwise. It fits the same height and memory reservation. A further conditional composition joins this view to the shared bus root and memory envelope below `2^-151`, assuming a valid common completion. Run `python3 doc/research/audits/zk_flock_columns_audit.py` for full-library bus checks, native ranks and the exact ledger. The paired source, not the former independent-per-position source, must be used in subsequent PCS analysis.

[body/flock/zk-flock-pair-opening.tex](body/flock/zk-flock-pair-opening.tex) rules out that block-local metadata source for full ZK: two PCS queries cancel its masks, with simulator-error floors above `2^-10` through `2^-17` across the supported rates. A second, globally permuted library preserves the partial theorem and breaks this cancellation, but full PCS privacy remains unproved. Run `python3 doc/research/audits/zk_flock_pair_opening_audit.py`, optionally with `--native`, for the exact obstruction, disjoint extension, native witness pair and authenticated encoder checks.

`check.py` checks the document input graph, note and citation references, audit links and the local audit import closure. It does not verify the mathematical claims. No Rust, Python or recursive production-verifier behaviour is changed by this project.
