How to reproduce

  • Install Rust with rustup.
  • Clone leanVM at the benchmarked commit: 
    git clone https://github.com/leanEthereum/leanVM
cd leanVM && git checkout
  • Aggregation: 
    LEANVM_NUM_THREADS=8 cargo leanvm aggregate --xmss 1500 --log-inv-rate 2 --repeat 3
  • Recursion 16 → 1: 
    LEANVM_NUM_THREADS=8 cargo leanvm recursion --n 16 --xmss-per-leaf 1500 --leaf-log-inv-rate 2 --log-inv-rate 1 --repeat 3
  • Set LEANVM_NUM_THREADS to 4 or 8, or leave it unset for full threads.

Time is the proving time line, RAM the peak memory next to it.
