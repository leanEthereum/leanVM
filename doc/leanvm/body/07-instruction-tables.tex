\section{The instruction tables}\label{sec:tables}

The instructions are grouped into eight \emph{classes}, and each class has its own table (\S\ref{sec:bytecode}). All eight tables are the same table: a row does the plumbing that every instruction needs, the state step, the bytecode read, the register accesses and the memory accesses, and what the class computes is a Boolean circuit proven by Flock (Annex~\ref{annex:flock}), one instance per row, whose words the row puts on the bus. The tables differ in which words their circuit has, whether the class has control flow, and how it touches memory.

Write $\rdf{\sep,\addr,\cnt,\val_0,\val_1, \dots}$ for the pair \pull\ $\tup{\sep,\addr,\cnt,\val_0,\val_1, \dots }$, \push\ $\tup{\sep,\addr,\gen\cdot\cnt,\val_0,\val_1, \dots}$: a read of a lookup array (\S\ref{sec:lookup}).

Write $\acc{k}\tup{\sep,a;\,v_{\mathrm{old}}\to v_{\mathrm{new}}}$ for the access, in slot $k$ of a row with clock $\ts$ (\S\ref{sec:memchan}), of the cell at address $a$ of the array under $\sep$. It is three flush pairs and one constraint over the access's own columns, $\tsprev_k,\glo_k,\ghi_k$ and the counts $r_{\mathrm{lo},k},r_{\mathrm{hi},k}$ of its two range reads:
\begin{align*}
  &\pull\ \tup{\sep,a,\tsprev_k,v_{\mathrm{old}}},\quad \push\ \tup{\sep,a,\gen^{k}\cdot\ts,v_{\mathrm{new}}},\\
  &\rdf{\dsep{RLO},\glo_k,r_{\mathrm{lo},k}},\qquad \rdf{\dsep{RHI},\ghi_k,r_{\mathrm{hi},k}},\\
  &\tsprev_k\cdot\glo_k=\gen^{k}\cdot\ts\cdot\ghi_k .
\end{align*}
A read is written $\acc{k}\tup{\sep,a;\,v}$, for $v_{\mathrm{old}}=v_{\mathrm{new}}=v$. A table's constraints are exactly its accesses' gap checks, one per access, and the columns listed below leave the accesses' five each implicit.

\subsection{The class table}\label{sec:tab-class}

\paragraph{The circuit's words.} A class's circuit (\S\ref{flock:classes}) reads and writes whole $64$-bit words, its \emph{ports}: the register values $v_1,v_2$, the bytecode's flags and immediate, the result, a memory cell, and so on, as the class needs. Flock packs the circuit's witness $64$ bits to a $\K$-element, so a port IS one word of the class's packed witness $\qcls{j}$, committed once (\S\ref{sec:e2e-unrolled}). The table commits none of these words again: they are \emph{virtual} columns, and a claim the bus raises on one of them at a row is routed to the same word of that row's instance in $\qcls{j}$ (\S\ref{sec:stacking}). Putting a port in a bus tuple is therefore what binds the circuit to the machine: the value it reads from a register is what the register tuple carries, the flags it decodes on are what the bytecode tuple carries, the result it computes is what the register write pushes. No constraint ties the two, because they are one committed value.

\paragraph{Columns.} The state $\pc,\ts$; the bytecode entry's register numbers $a_1,a_2$ and successor $\pc^{+}$; the two values read, $v_1,v_2$, and the flags, which are ports; then, for a class that writes a register, $a_d$, the old value $v_d^{\mathrm{old}}$ and the result $\mathit{out}$ (a port); for a class with control flow, the bytecode's $\Delta,\mathit{link},\mathit{jalr}$ and the port $b$; the immediate $\mathit{imm}$ (a port) if the circuit takes one; the memory words below; and the bytecode count $r_{\mathrm{bc}}$. A word is $64$ bits and a register holds one, so every port that reaches a tuple is a $\K$-element as it stands.

\paragraph{Flushes.}
\begin{itemize}
  \item \textbf{State:} \pull\ $\tup{\dsep{ST},\pc,\ts}$, \push\ $\tup{\dsep{ST},\pc',\gen^{s}\cdot\ts}$, where the next $\pc$ and the stride $s$ are the class's (below): $\pc'=\pc^{+}$ and $s=4$ unless said otherwise.
  \item \textbf{Bytecode:} $\rdf{\dsep{BC},\pc,r_{\mathrm{bc}},\opc{j},\mathit{flags},a_1,a_2,a_d,\mathit{imm},\pc^{+},\Delta,\mathit{link},\mathit{jalr}}$, the last three for the control class only, and a constant in place of a column the row has not: $\intk{\sink}$ for $a_d$ and $0$ for $\mathit{imm}$, which the entry then has to hold (\S\ref{sec:e2e-bc}).
  \item \textbf{Registers:} $\acc{0}\tup{\dsep{REG},a_1;\,v_1}$, $\acc{1}\tup{\dsep{REG},a_2;\,v_2}$, and $\acc{3}\tup{\dsep{REG},a_d;\,v_d^{\mathrm{old}}\to v_d}$ for a class that writes one, with $v_d=\mathit{out}$ unless said otherwise.
  \item \textbf{Memory:} the class's accesses, in slot $2$ and up.
\end{itemize}
A padding row (\S\ref{sec:e2e-pad}) is a row of the class's no-op instruction on zero registers, its circuit instance an honest one.

\subsection{The classes}\label{sec:tab-classes}

The instructions of rv64im are decoded into the eight classes below, an entry's flags selecting one function of its class (\S\ref{sec:e2e-bc}); \texttt{lui}, \texttt{auipc} and \texttt{jal} are constants added to $\regs[0]$, \texttt{fence} is an addition of zeros, and \texttt{ecall} a jump to the halt slot. The reference for every function is the specification~\cite{riscv}; \S\ref{flock:classes} gives the circuits.

\paragraph{\texttt{ALU}} (arithmetic, comparisons, bitwise logic, branches and jumps). Ports $v_1,v_2,\mathit{imm},\mathit{flags}\to\mathit{out},b$. The second operand is $v_2\oplus\mathit{imm}$, the decoder making one of the two zero, and $b\in\{0,1\}$ is whether the branch is taken, a whole port so that Flock's empty rows force its other $63$ bits to zero. This is the one class with control flow, and the row derives what it pushes rather than committing it (\S\ref{sec:m3}):
\[
  \pc'=\pc^{+}+b\,\Delta+\mathit{jalr}\,(\mathit{out}+\pc^{+}),\qquad v_d=\mathit{out}+\mathit{link}\,(\mathit{out}+\pc^{+}),
\]
each of degree two, where the bytecode's $\Delta$ is the branch target XOR $\pc^{+}$, so that $\pc^{+}+\Delta$ is the target, and $\mathit{link},\mathit{jalr}\in\{0,1\}$ select \texttt{jal}'s link and \texttt{jalr}'s computed target, both zero elsewhere.

\paragraph{\texttt{LOAD}.} Ports $v_1,\mathit{imm},\mathit{flags},\mathit{cell}\to\mathit{address},\mathit{out}$: the circuit adds the address, extracts the bytes the width and the offset select from the cell and extends them, and hands the bus the word's address with the misalignment bits in it (\S\ref{sec:exp}). One access, $\acc{2}\tup{\dsep{MEM},\mathit{address};\,\mathit{cell}}$.

\paragraph{\texttt{STORE}.} Ports $v_1,v_2,\mathit{imm},\mathit{flags},\mathit{cell}\to\mathit{address},\mathit{cell}',\mathit{out}$, the new cell being the old one with the stored bytes replaced and $\mathit{out}=0$, the sink's. One access, $\acc{2}\tup{\dsep{MEM},\mathit{address};\,\mathit{cell}\to\mathit{cell}'}$.

\paragraph{\texttt{SHIFT}, \texttt{MUL}, \texttt{MULH}.} Ports $v_1,v_2,\mathit{imm},\mathit{flags}\to\mathit{out}$ for the shifts (the amount being the low bits of $v_2\oplus\mathit{imm}$), $v_1,v_2,\mathit{flags}\to\mathit{out}$ for the low and the high word of a product.

\paragraph{\texttt{DIV}} (division and remainder). Ports $v_1,v_2,\mathit{flags},q,r\to\mathit{out},\mathit{bad}$. The circuit does not divide: the prover supplies a quotient and a remainder, $q$ and $r$, as \emph{hints}, ports that are in the witness and in no column, and the circuit checks $v_1=q\cdot v_2+r$ over the integers with $r<|v_2|$, and the specification's cases for a zero divisor and the overflow. The check's verdict is the word $\mathit{bad}$, nonzero on a wrong hint, which the row puts in slot $13$ of its bytecode tuple: the program is zero there, so by Theorem~\ref{thm:omc} a row with $\mathit{bad}\neq0$ reads no entry.

\paragraph{\texttt{HASH}} (\texttt{blake2s}). Ports $v_2,\mathit{flags},h_0,\dots,h_3,m_0,\dots,m_7\to\mathit{out}_0,\dots,\mathit{out}_3$: the counter is the second register and the finalization word the flags (\S\ref{sec:vm}). The row writes no register, so it has no $a_d,v_d^{\mathrm{old}},\mathit{out}$ columns and reads $\intk{\sink}$ off the entry, and it has no immediate. Its block is sixteen accesses at $v_1+\intk{8k}$ (\S\ref{sec:exp}), in slots $2$ to $17$, so its stride is $s=18$: reads of the chaining value and the message, whose words are ports, and writes of the result, whose old values $\mathit{out}^{\mathrm{old}}_k$ are four committed columns like $v_d^{\mathrm{old}}$:
\begin{align*}
  &\acc{2+k}\tup{\dsep{MEM},v_1+\intk{8k};\,h_k}\quad(k<4),\qquad
  \acc{2+k}\tup{\dsep{MEM},v_1+\intk{8k};\,m_{k-8}}\quad(8\le k<16),\\
  &\acc{2+k}\tup{\dsep{MEM},v_1+\intk{8k};\,\mathit{out}^{\mathrm{old}}_{k-4}\to\mathit{out}_{k-4}}\quad(4\le k<8).
\end{align*}
The result cannot be written over the chaining value, because a padding row must rewrite what it writes (\S\ref{sec:e2e-pad}) and no chaining value is a fixed point of the compression.

\paragraph{Sizes.} A circuit's instance occupies $2^{\kblock}$ bits, $10$ for \texttt{ALU}, \texttt{LOAD}, \texttt{STORE} and \texttt{SHIFT}, $12$ for \texttt{MUL}, $13$ for \texttt{MULH} and \texttt{DIV}, $14$ for \texttt{HASH} (\S\ref{flock:classes}). Flock proves a batch of at least $2^{13}$ bits and at least eight instances, so a table has at least $2^{3}$ rows, and at least $2^{13-\kblock}$; padding rows (\S\ref{sec:e2e-pad}) supply them.
